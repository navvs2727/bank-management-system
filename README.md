# Bank Management System (Python + MySQL)

This is a Bank Management System built using Python and MySQL.

## Features

- Login System
- Create Account
- Deposit Money
- Withdraw Money
- Search Account
- Delete Account
- Transaction History

## Technologies Used

Python  
MySQL

## How to Run

1 Install MySQL

2 Create database using database.sql

3 Install dependencies

pip install -r requirements.txt

4 Run the project

python main.py
